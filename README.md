
# LeetCode Practice

This repository contains my solutions to various LeetCode problems. Each problem is organized into its own folder, named after the problem. Inside each folder, you'll find:

- A `README.md` file with the problem description.
- A Python file (`solution.py`) containing my solution.

## Structure

```
LeetCode-Practice/
├── Problem-1/
│   ├── README.md
│   └── solution.py
├── Problem-2/
│   ├── README.md
│   └── solution.py
├── Problem-N/
│   ├── README.md
│   └── solution.py
```

## How to Use

1. Navigate to the folder of the problem you're interested in.
2. Read the problem description in the `README.md` file.
3. Check out my solution in the `solution.py` file.

Feel free to use these solutions as a reference, but I encourage you to try solving the problems on your own first!
